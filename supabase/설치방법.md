# 상담 신청 받기 설치 (Supabase + Resend)

방문자가 helprnd.com 팝업에서 신청하면
**Supabase 데이터베이스(leads 표)에 저장**되고 **Resend로 알림 메일**이 옵니다.

> 비밀번호와 API 키는 **직접 입력**해 주세요. 대화창에 붙여 넣지 마세요.

---

## 1. Supabase 프로젝트 만들기
1. https://supabase.com/dashboard → **New organization**
   - Name: `helprnd` · Type: Personal · Plan: **Free** → Create
2. **New project**
   - Name: `helprnd`
   - Database Password: **Generate a password** → 안전한 곳에 따로 저장 (이번 설정에는 다시 쓰지 않음)
   - Region: **Northeast Asia (Seoul)** ← 한국 서버. 꼭 이걸로
   - **Create new project** → 1~2분 기다림

## 2. 표(테이블) 만들기
1. 왼쪽 메뉴 **SQL Editor** → **New query**
2. `schema.sql` 내용을 통째로 붙여 넣고 **Run**
3. "Success. No rows returned" 가 나오면 완료
   (왼쪽 **Table Editor** 에 `leads` 표가 생깁니다)

## 3. Resend API 키 만들기
1. https://resend.com/api-keys → **Create API Key**
   - Name: `helprnd` · Permission: **Sending access** → Add
2. `re_` 로 시작하는 키가 **한 번만** 보입니다. 바로 복사해 두세요.

## 4. 신청 받는 함수(lead) 올리기
1. Supabase 왼쪽 메뉴 **Edge Functions** → **Deploy a new function** → **Via Editor**
2. 함수 이름: `lead`
3. 편집기 내용을 지우고 `functions/lead/index.ts` 내용을 통째로 붙여 넣기 → **Deploy function**
4. 배포가 끝나면 함수 화면의 **Details(또는 Settings)** 에서
   **Enforce JWT verification(Verify JWT)** 를 **끄고** 저장
   (사이트 방문자는 로그인하지 않으므로 꺼야 신청이 들어옵니다. 보안은 함수 안에서 따로 검사합니다)

## 5. 비밀 값(Secrets) 넣기
**Edge Functions → Secrets** (또는 Project Settings → Edge Functions) 에서 아래 3개를 추가 → Save

| Name | Value |
|---|---|
| `RESEND_API_KEY` | 3번에서 복사한 `re_…` 키 |
| `NOTIFY_EMAIL` | 알림 받을 메일 (예: juddmank@gmail.com) |
| `FROM_EMAIL` | `HelpR&D <onboarding@resend.dev>` |

> 지금은 Resend 테스트 주소(onboarding@resend.dev)로 보내기 때문에 **Resend 가입 메일 주소로만** 알림이 갑니다.
> helprnd.com 도메인을 Resend에 인증하면 `noreply@helprnd.com` 으로 보내고, 신청자 자동 답장(`AUTOREPLY` = `on`)도 켤 수 있습니다.
